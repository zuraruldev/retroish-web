# Retro Web Space

A 90s OS retro-themed personal website.

## Live Preview
[https://arul.cc.cd](https://arul.cc.cd)

## Features
- Windows 95/98 desktop aesthetic
- Draggable and minimizable windows
- Interactive MS-DOS terminal prompt
- Guestbook and CRT scanline filter toggle
- Zero dependencies (vanilla HTML, CSS, JavaScript)

## Deployment
Hosted on VPS behind Nginx and Cloudflare Tunnel.
Pull changes directly to `/var/www/arul.cc.cd`:
```bash
git pull origin main
```
